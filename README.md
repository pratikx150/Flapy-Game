best v# Flapy Game

Everything is local — no internet needed.

```
Flapy-Game/
├── index.html
├── css/style.css
├── js/script.js
└── assets/
    ├── images/  background.png, bird.png, pipe.svg, follower1.svg, follower2.svg
    └── audio/   fly.mp3, catch.mp3, lose.mp3
```

Run: serve the folder over http (Replit, or `python -m http.server 8000` → http://localhost:8000).

To change a picture, replace the file with the same name (keep transparent background for bird.png).
