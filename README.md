# Flapy Game

Everything is local — no internet needed.

```
Flapy-Game/
├── index.html
├── css/style.css
├── js/script.js
└── assets/
    ├── images/  background.png, pipe.svg, face_main.png (player), face_follower1.png, face_follower2.png
    └── audio/   fly.mp3, catch.mp3, lose.mp3
```

Run: serve the folder over http (Replit, or `python -m http.server 8000` → http://localhost:8000).

To change a picture, replace the file with the same name (face_main.png = player bird head, face_follower1/2.png = the two followers — square images, face centred).
