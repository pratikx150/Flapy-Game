Vercel API Ready

Email Avatar API

Use the endpoint below to get the real Gravatar profile image for any email address in JSON format.

https://your-vercel-project-url.vercel.app/api/avatar?email=hello@example.com

Example response:

{
  "success": true,
  "email": "hello@example.com",
  "avatar": "https://www.gravatar.com/avatar/....?s=512&d=mp&r=g",
  "avatar_url": "https://www.gravatar.com/avatar/....?s=512&d=mp&r=g",
  "pfp": "https://www.gravatar.com/avatar/....?s=512&d=mp&r=g",
  "profile_picture": "https://www.gravatar.com/avatar/....?s=512&d=mp&r=g",
  "provider": "gravatar"
}

You can also call:

/api/avatar?mail=hello@example.com

Works on Vercel as a serverless API route.
